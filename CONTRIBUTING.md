# Contributing

Useful improvements make this layout easier to read, customize, or maintain.

Welcome changes include clearer setup steps, accessible colors and alternative text, fixes for narrow screens, and small improvements to project presentation. Keep the live example and neutral template structurally aligned.

For a pull request, explain the problem and the change. Include light- and dark-theme screenshots at desktop and mobile widths for visual changes. Check relative links from the repository root and try the customization instructions with a fictional identity.

Keep the template usable through GitHub's editor alone. Discuss major redesigns first; avoid adding widgets, tracking, external fonts, build tools, or automated activity updates. Do not add fabricated project metrics or another person's biography to the neutral template.

Original template, design, and documentation contributions are accepted under the repository's MIT license. Include sources and permission details for any external assets; original assets are preferred.
