Title: Minimal profile layout — first release

A reusable GitHub profile for developers building AI tools. Includes a working personal example, a neutral Markdown template, an editable SVG banner, light/dark previews, and step-by-step setup for new or existing profile repositories. No packages, tokens, or GitHub Actions required. The reusable layout and assets are MIT licensed.

Start with [the customization guide](CUSTOMIZE.md). [Download the shareable preview](assets/previews/share.png).

## Announcement draft

I rebuilt my GitHub profile as a minimal layout other builders can reuse: two project showcases, a little context, selected writing, and a clear way to connect.

It uses Markdown and one editable SVG. No stats services, setup scripts, or API keys. The repository includes a neutral template and instructions for both new and existing profile repositories.

Live example and setup: https://github.com/mihaibc/mihaibc

If you try it, I'd especially like feedback on mobile readability and any setup step that was unclear.
